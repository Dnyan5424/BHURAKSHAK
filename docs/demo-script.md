# Demo script (about 4 min)
1. 0:00 Landing page: problem in one line; show the "not a legal determination" notice.
2. 0:30 Public map: toggle before/after imagery; click the Critical polygon; read "Why this was flagged".
3. 1:15 Report page: pick a location near a polygon, submit, note the Petition ID and the "matches an area under review" message.
4. 2:00 Track page with that ID + mobile; show the official portal link and the redirect notice.
5. 2:30 Officer sign-in: open the queue, add remarks, mark "Potential Violation" (note the required fields), download the PDF.
6. 3:30 Admin: KPIs, risk chart, CSV export. Close: all demo data is synthetic.
