# Pitch deck (7 slides)
1. Problem: land-use change is found late and complaints are hard to verify.
2. Solution: satellite change detection + citizen reports + officer verification.
3. How it works: before/after indices (NDVI/NDWI/NDBI/BSI), GIS context, confidence and risk score.
4. Safeguards: never declares illegality; only an officer decides; public sees safe statuses only.
5. Demo: map, petition, officer decision, PDF report.
6. Data and cost: free Sentinel-2 and OpenStreetMap; runs on SQLite or PostgreSQL.
7. Roadmap: live Sentinel-2 ingestion, SMS alerts, land-record integration, field app.
